# BHS 스키아카데미 사이트 전면 개선 설계

날짜: 2026-08-26

## 목표

현재 기능 검증용 UI를 공식 운영에 적합한 반응형 웹 애플리케이션으로 전면
개선한다. 사이트를 처음 연 학부모와 관리자가 전문 업체가 체계적으로 만든
서비스라는 인상을 받도록 하며, 모바일과 PC 모두에서 실제 운영 작업이 빠르고
명확해야 한다.

기존의 반편성, 쿠폰 차감·복구, 공개 조회 및 관리자 인증 흐름은 유지한다.

## 확정된 시각 방향

- 사용자가 제공한 `배호성 동그라미 로고.PNG`를 공식 로고 원본으로 사용한다.
  로고의 글자, 별, 원형 테두리, 스키 폴을 다시 그리거나 변형하지 않는다.
- 선택된 스타일은 **프리미엄 알파인**이다.
- 짙은 네이비를 주 배경, 공식 로고의 파란색과 설원 블루를 강조색, 밝은
  스노 화이트를 콘텐츠 배경으로 사용한다.
- 장식보다 정보 위계와 정렬을 우선한다. 날짜 → 시간대 → 반 → 선생님 →
  학생의 관계가 즉시 읽혀야 한다.
- 모바일 터치 대상은 최소 44px로 하고, 상태는 색상만으로 표현하지 않는다.
- 로딩, 빈 상태, 오류, 성공 상태를 모두 같은 디자인 언어로 제공한다.

## 반응형 구조

하나의 UI·컴포넌트 체계를 유지하면서 화면 폭에 따라 정보 구조를 재배치한다.

### 모바일

- 상단에 공식 로고와 화면명을 표시하는 컴팩트 브랜드 헤더
- 한 화면에서 하나의 주요 작업에 집중하는 단일 열 구조
- 날짜와 오전·오후 선택을 상단에 고정된 컨트롤로 제공
- 반 카드는 선생님, 학생 수, 학생 명단, 쿠폰 잔여 상태 순서로 표시
- 새 반 만들기 같은 주요 동작은 하단에서 쉽게 누를 수 있게 배치
- 학생 배정과 쿠폰 충전은 검색 가능한 전용 시트/패널을 사용

### PC

- 브랜드와 주요 관리 메뉴를 담은 사이드바
- 넓은 콘텐츠 영역에서 오전·오후 반편성을 동시에 비교
- 아이·선생님·쿠폰 관리에서는 검색 및 요약과 목록을 함께 표시
- 모바일과 동일한 용어, 색상, 상태 체계를 유지

## 학부모 화면

- 공식 로고와 아카데미 이름이 들어간 프리미엄 알파인 헤더
- 오늘·내일 날짜 선택과 선택된 날짜의 전체 표기
- 오전·오후 섹션과 선생님별 반 카드
- 각 카드에 선생님 이름, 학생 수, 학생 명단 표시
- 마지막 갱신 시각과 수동 새로고침 제공
- 최초 로딩, 갱신 중, 통신 실패, 반편성 전 상태를 서로 구분
- 쿠폰 정보나 관리자용 데이터는 절대 노출하지 않음
- 30초 자동 갱신은 유지하되 기존 내용이 사라지거나 화면이 튀지 않게 처리

## 관리자 공통 구조

- 모바일은 상단/하단 탐색, PC는 사이드바 탐색을 사용
- 메뉴: 반편성, 아이·쿠폰, 선생님 관리
- 모든 생성·수정·삭제 요청은 처리 중 상태를 보여주고 중복 제출을 막음
- 성공은 짧은 완료 메시지, 실패는 원인과 재시도 동작을 제공
- 삭제나 쿠폰에 영향을 주는 작업은 명확한 확인 단계를 거침
- 브라우저 기본 `prompt`에 의존하는 입력 흐름은 전용 폼이나 다이얼로그로 교체

## 반편성 관리

- 모바일: 날짜 → 오전/오후 → 반 카드 순서로 집중 조작
- PC: 선택한 날짜의 오전·오후 반을 두 열에서 동시에 확인
- 반 생성 시 시간대와 선생님을 명시적으로 선택
- 생성된 반의 담당 선생님 변경 지원
- 반 삭제 시 배정 학생 수와 쿠폰 복구 사실을 확인 문구에 포함
- 학생 배정 패널에서 이름 검색, 메모, 잔여 쿠폰을 함께 표시
- 배정과 취소가 완료되면 반 카드와 쿠폰 잔액을 즉시 갱신
- 잔여 쿠폰이 0 이하인 학생도 기존 운영 정책대로 배정 가능하되 강한 경고 표시
- 같은 학생의 같은 시간대 중복 배정도 기존 정책대로 허용

## 아이·쿠폰 관리

- 이름 검색과 잔여 쿠폰 상태 필터 제공
- 아이 등록 시 이름과 메모 입력
- 목록에서 이름, 메모, 잔여 쿠폰을 한눈에 확인
- 쿠폰 충전은 전용 입력 폼에서 횟수와 확인 단계를 제공
- 쿠폰 이벤트 이력을 최신순으로 표시하고 충전·배정 차감·취소 복구를 구분
- 잔여 쿠폰은 계속 이벤트 합계로 계산하며 별도 잔액 컬럼을 만들지 않음

## 선생님 관리

- 선생님 등록 및 활성 목록 관리
- 각 선생님의 현재 활성 상태와 선택 날짜 담당 반 현황을 명확히 표시
- 이미 반에 연결된 선생님 제외 시 데이터 관계를 훼손하지 않는 기존 비활성화
  정책을 유지

## 데이터와 API 변경

기존 Prisma 모델과 트랜잭션 원칙을 유지한다. UI 개선에 필요한 최소 API만
확장한다.

- 반 담당 선생님 변경 API
- 학생별 쿠폰 이벤트 이력 조회 API
- 필요한 경우 목록 검색·필터 파라미터

공개 API에는 계속 날짜별 반, 선생님 이름, 학생 이름만 포함한다. 쿠폰 잔액,
메모, 이력, 관리자 상태는 반환하지 않는다.

## 오류와 경계 상황

- 네트워크 오류 시 기존 데이터를 유지하고 재시도 안내를 표시
- 빈 목록은 원인과 다음 행동이 보이는 안내 화면으로 표시
- 처리 중 버튼은 비활성화하고 진행 상태를 명시
- API의 유효성 검증 실패는 가능한 한 구체적인 한국어 메시지로 변환
- 삭제, 배정 취소, 쿠폰 충전 실패 시 화면을 성공 상태로 먼저 바꾸지 않음
- 서버 응답 후 관련 데이터만 다시 불러와 화면과 DB 상태를 일치시킴

## 접근성과 품질

- 키보드 포커스, 폼 레이블, 상태 텍스트, 충분한 대비를 제공
- 모바일 360px부터 넓은 PC 화면까지 레이아웃이 깨지지 않아야 함
- 동작 버튼은 의미와 결과가 분명한 한국어를 사용
- 과한 애니메이션을 배제하고 필요한 상태 전환만 짧게 사용

## 검증 기준

- 기존 쿠폰, 날짜, 인증, 배정 자동 테스트가 모두 통과
- 새 반 담당 선생님 변경과 쿠폰 이력 API 테스트 추가
- 학부모 공개 API에 관리자 정보가 섞이지 않는지 검증
- 모바일과 PC 뷰포트에서 학부모·로그인·관리자 주요 화면 시각 확인
- 반 생성 → 학생 배정 → 쿠폰 차감 → 배정 취소 → 쿠폰 복구 흐름 수동 확인
- `npm test`, `npm run lint`, `npm run build` 통과

## 완료 조건

- 전달받은 공식 로고가 학부모, 관리자 로그인, 관리자 대시보드에 일관되게 적용됨
- 모바일과 PC 모두 임시 확장 화면이 아닌 기기별로 설계된 구조로 보임
- 학부모가 날짜와 자기 아이의 반을 빠르게 찾을 수 있음
- 관리자가 반 생성, 학생 배정, 쿠폰 관리를 기본 브라우저 팝업 없이 수행 가능
- 모든 핵심 작업에 로딩·성공·오류 피드백이 있음
- 기존 데이터 정책과 쿠폰 트랜잭션 안전성이 유지됨
